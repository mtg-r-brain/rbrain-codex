# MTG R.brain — Project Vision

Founding session: 2026-06-10

## What it is

An AI-powered reasoning platform built around Magic: The Gathering.
Functionally inspired by existing MTG AI tools (rules agents, deck-building agents),
but with a fully distinct identity, original branding, and a radically leaner stack.

**No wording borrowed from competing projects.** No character names lifted from other tools.

## Core features identified

- **Rules agent**: answer MTG rules questions with cited sources (Comprehensive Rules, community
  sources). Multi-format support: Standard, Pioneer, Modern, Legacy, Vintage, Commander, Pauper.
- **Deck agent**: analyze an uploaded deck (synergies, weaknesses), build a deck from scratch.
- Conversational chat with history (requires account).
- Deck upload — formats: MTGA, MTGO, plain text.
- Editorial blog.
- User accounts (free tier; saves decks and chat history).
- Discord community integration.

## Identity

Name: **MTG R.brain** (R = Reasoning)
Repository prefix: `rbrain-`
Internal naming: project-specific, not borrowed from competitors.

## Positioning

Specialized alternative to generic chatbots for MTG.
Differentiators to be defined during spec phases (source quality, UX, open-source strategy?).
