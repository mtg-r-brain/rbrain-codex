## Context

`repository-conventions` is the cross-repo convention spec every `rbrain-*` repo conforms to. Finding C (incomplete archive commits) recurs because the archive operation moves files without staging them, and the intuitive `git add <newpath>` misses the deletions. The two archive mechanisms differ in *how* they move (skill: `mv`; CLI: copy+delete) but share the same git-staging gap.

## Goals / Non-Goals

**Goals:** a durable, tool-agnostic convention that prevents the incomplete-archive-commit class of bug across all repos.

**Non-Goals:** editing the generated `openspec-archive-change` skill (regenerated by `openspec update`, so not durable); changing the `openspec` CLI (third-party — separate upstream feedback); a git hook (heavier; the convention + review is sufficient at this scale).

## Decisions

### Decision 1: Codify `git add -A openspec/`, not a skill patch

A convention in `repository-conventions` is durable and inherited by every repo, where a local `SKILL.md` edit is not (auto-generated). `git add -A openspec/` is correct for both archive mechanisms and for the canonical-spec update, regardless of whether the move was a `mv` or a copy+delete.

### Decision 2: Scope the stage to `openspec/`, not the whole tree

`git add -A openspec/` stages the change move + canonical spec update without sweeping unrelated working-tree changes into the archive commit — keeping the archive commit atomic (it should contain only the archive).

### Decision 3: Review-enforced, not CI-enforced (for now)

The convention is enforced at review (and by agent discipline): an archive commit that still contains the pre-archive `openspec/changes/<name>/` directory is rejected. A CI check (e.g. "no non-archive change dir was both added and left") could follow if the friction persists; not built now.

## Risks / Trade-offs

- **Convention can be forgotten** like any guideline. Mitigated by making it explicit in the canonical spec and by the agent handoff pointer; escalate to a hook/CI check if Finding C recurs after this lands.

## Migration

None — documentation/convention.
